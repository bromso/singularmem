# Scoping (Sub-project 12) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every item an optional hierarchical scope path and thread a descendant-inclusive scope filter through the store, both search rankers, the retriever, the ingest defaults, the CLI, the MCP server, and the Node binding.

**Architecture:** `singularmem-core` gains a `scope` module (validation + ancestors), a `ScopeFilter` value, store format v3 (nullable `scope` column, 2→3 migration chained after 1→2), scoped list methods, `scopes()`, `scope_of()`, `set_scope()`. `singularmem-search` adds `scope` + multi-valued `scope_ancestors` fields (existing sidecars fail with `IndexSchemaMismatch` until `reindex`), a lexical `Must` clause, and a `ScopeLookup` trait for post-filtering semantic hits. Retrieve passes the filter through; the ingest crate's `Source` gains `default_scope`; CLI/MCP/Node expose flags, a `scope` verb group, `memory_scopes`, and `scopes()`/`setScope()`.

**Tech Stack:** Rust 1.80, rusqlite 0.32, tantivy 0.22.1, usearch 2.15.3, clap 4, rmcp, napi-rs 2, proptest, assert_cmd.

## Global Constraints

- Scope string: 1–8 segments separated by `/`; each segment 1–64 bytes matching `[A-Za-z0-9._-]+`; total ≤ 512 bytes; normalised to lowercase, no leading/trailing `/`, no empty segments, no `.` or `..` segments.
- Descendant filter matches the scope and every scope beneath it; `exact` matches only the scope itself. Unscoped queries match everything.
- `FORMAT_VERSION = "3"`; export marker stays `"export-v1"`; `store_format_version` reports `"3"`.
- Migration 2→3 is exactly: `ALTER TABLE items ADD COLUMN scope TEXT;` `CREATE INDEX idx_items_scope ON items(scope) WHERE scope IS NOT NULL;` `UPDATE singularmem_meta SET value = '3' WHERE key = 'format_version';` in one `BEGIN IMMEDIATE` transaction with an in-transaction version re-check. v1 stores run 1→2 then 2→3. Read-only opens of v1/v2 refuse with `Error::Migration`.
- Ingest defaults: transcript → `claude-code/<basename of cwd>`; directory → `files/<basename of canonical root>`; plain `ingest` → none. `--scope` overrides. A basename failing validation yields no scope plus a warn.
- Scoped semantic search overfetches `limit * fetch_multiplier * 2`.
- Workspace lints: clippy pedantic + nursery, `-D warnings`; `cargo fmt --all -- --check`; no network in tests (`SINGULARMEM_TEST_EMBEDDER=mock`); `#![forbid(unsafe_code)]`.
- Every commit signed off (`git commit -s`). Branch `scoping-12` (stacked on `transcript-ingestion-11`). One PR at the end.

//! Scope paths: validation, normalisation, ancestor expansion, and the
//! filter value threaded through every read surface.
//!
//! Spec: `docs/formats/store-v3.md` § "Scope".

use serde::{Deserialize, Serialize};

use crate::error::{Error, Result};

/// Maximum number of `/`-separated segments.
pub const MAX_SEGMENTS: usize = 8;
/// Maximum bytes per segment.
pub const MAX_SEGMENT_BYTES: usize = 64;
/// Maximum bytes for the whole normalised path.
pub const MAX_SCOPE_BYTES: usize = 512;

/// Validate and normalise a scope path.
///
/// Lowercases, strips leading/trailing slashes, and rejects empty, `.`,
/// `..`, or non-`[a-z0-9._-]` segments, more than [`MAX_SEGMENTS`]
/// segments, segments over [`MAX_SEGMENT_BYTES`], or a total over
/// [`MAX_SCOPE_BYTES`].
///
/// # Errors
/// `Error::Validation { field: "scope", .. }` describing the first rule broken.
pub fn validate(raw: &str) -> Result<String> {
    let trimmed = raw.trim_matches('/');
    let reject = |reason: String| Error::Validation { field: "scope", reason };
    if trimmed.is_empty() {
        return Err(reject("must contain at least one segment".into()));
    }
    let mut segments = Vec::new();
    for seg in trimmed.split('/') {
        if seg.is_empty() {
            return Err(reject("empty segment (double slash)".into()));
        }
        if seg == "." || seg == ".." {
            return Err(reject(format!("segment {seg:?} is not allowed")));
        }
        if seg.len() > MAX_SEGMENT_BYTES {
            return Err(reject(format!("segment exceeds {MAX_SEGMENT_BYTES} bytes")));
        }
        let lower = seg.to_ascii_lowercase();
        if !lower.bytes().all(|b| b.is_ascii_lowercase() || b.is_ascii_digit() || matches!(b, b'.' | b'_' | b'-')) {
            return Err(reject(format!("segment {seg:?} contains characters outside [A-Za-z0-9._-]")));
        }
        segments.push(lower);
    }
    if segments.len() > MAX_SEGMENTS {
        return Err(reject(format!("more than {MAX_SEGMENTS} segments")));
    }
    let joined = segments.join("/");
    if joined.len() > MAX_SCOPE_BYTES {
        return Err(reject(format!("exceeds {MAX_SCOPE_BYTES} bytes")));
    }
    Ok(joined)
}

/// Every prefix of a normalised scope, shortest first, ending with the
/// scope itself. Input is assumed normalised (call [`validate`] first).
#[must_use]
pub fn ancestors(scope: &str) -> Vec<String> {
    let mut out = Vec::new();
    let mut acc = String::new();
    for seg in scope.split('/') {
        if !acc.is_empty() {
            acc.push('/');
        }
        acc.push_str(seg);
        out.push(acc.clone());
    }
    out
}

/// A scope filter: `path` plus whether descendants are included.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct ScopeFilter {
    /// Normalised scope path.
    pub path: String,
    /// `true` → only items whose scope equals `path`; `false` → `path` and
    /// everything beneath it.
    pub exact: bool,
}

impl ScopeFilter {
    /// Descendant-inclusive filter; validates and normalises `path`.
    ///
    /// # Errors
    /// Same as [`validate`].
    pub fn descendants(path: &str) -> Result<Self> {
        Ok(Self { path: validate(path)?, exact: false })
    }

    /// Exact-match filter; validates and normalises `path`.
    ///
    /// # Errors
    /// Same as [`validate`].
    pub fn exact(path: &str) -> Result<Self> {
        Ok(Self { path: validate(path)?, exact: true })
    }

    /// Does a stored scope satisfy this filter?
    #[must_use]
    pub fn matches(&self, scope: Option<&str>) -> bool {
        match scope {
            None => false,
            Some(s) if self.exact => s == self.path,
            Some(s) => s == self.path || s.strip_prefix(self.path.as_str()).is_some_and(|rest| rest.starts_with('/')),
        }
    }

    /// SQL fragment and bound parameters for a `WHERE` clause on `items.scope`.
    /// Uses `ESCAPE '\'` because `_` is a LIKE wildcard and a legal scope byte.
    #[must_use]
    pub(crate) fn sql_clause(&self) -> (&'static str, Vec<String>) {
        if self.exact {
            ("scope = ?", vec![self.path.clone()])
        } else {
            let escaped = self.path.replace('\\', "\\\\").replace('%', "\\%").replace('_', "\\_");
            ("(scope = ? OR scope LIKE ? ESCAPE '\\')", vec![self.path.clone(), format!("{escaped}/%")])
        }
    }
}

        let mut sql = String::from("SELECT i.id FROM items i WHERE 1=1");
        let mut params: Vec<String> = Vec::new();
        if !tags.is_empty() {
            let placeholders = vec!["?"; tags.len()].join(", ");
            sql.push_str(&format!(
                " AND i.id IN (SELECT item_id FROM item_tags WHERE tag IN ({placeholders}) \
                  GROUP BY item_id HAVING COUNT(DISTINCT tag) = ?)"

            params.push(tags.len().to_string());

            let (clause, binds) = f.sql_clause();
            sql.push_str(" AND ");
            sql.push_str(&clause.replace("scope", "i.scope"));

        sql.push_str(" ORDER BY i.created_at ASC");

            .query_map(rusqlite::params_from_iter(params.iter()), |r| r.get::<_, String>(0))
            .map_err(|e| Error::Sqlite { context: "executing scoped list query", source: e })?
            .collect::<rusqlite::Result<Vec<String>>>()
            .map_err(|e| Error::Sqlite { context: "collecting scoped list IDs", source: e })?;
        drop(stmt);
        drop(conn);
        let pending_ids = id_strings.into_iter().map(|s| s.parse::<ItemId>()).collect::<std::result::Result<VecDeque<_>, _>>()?;

    /// revision. This is the store's second sanctioned in-place mutation
    /// (`docs/formats/store-v3.md`). Index hooks are NOT notified: the Tantivy

    /// # Errors

    /// `Error::NotFound`, `Error::Sqlite`.
    ///
    /// # Panics
    /// Panics if the connection `Mutex` is poisoned.
    pub fn set_scope(&self, id: ItemId, scope: Option<&str>) -> Result<Item> {

            }
        }
