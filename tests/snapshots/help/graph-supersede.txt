Replace OLD with NEW at one instant, in one transaction

Usage: singularmem graph supersede [OPTIONS] <SUBJECT> <PREDICATE> <OLD> <NEW>

Arguments:
  <SUBJECT>    
  <PREDICATE>  
  <OLD>        
  <NEW>        

Options:
      --store <PATH>  Path to the `SQLite` store file. Defaults to the per-user XDG data dir. Also
                      settable via the `SINGULARMEM_STORE` environment variable — the only way to
                      point a hook (which runs with a fixed, flag-less command line) at a
                      non-default store
      --value         
      --at <TS>       
      --read-only     Open the store in read-only mode (refuses ingest)
      --no-index      Skip wiring up the Tantivy hook on open. Use for storage-only operations that
                      don't need search, or when the Tantivy directory is intentionally absent
      --scope <PATH>  
  -h, --help          Print help
