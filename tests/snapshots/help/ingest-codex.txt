Bulk-ingest `OpenAI` Codex CLI rollout JSONL files (idempotent)

Usage: singularmem ingest-codex [OPTIONS] [PATHS]...

Arguments:
  [PATHS]...  Rollout files or directories (searched recursively for `rollout-*.jsonl`). Defaults to
              `~/.codex/sessions`

Options:
      --project <DIR>  Keep only messages whose session `cwd` equals DIR
      --store <PATH>   Path to the `SQLite` store file. Defaults to the per-user XDG data dir. Also
                       settable via the `SINGULARMEM_STORE` environment variable — the only way to
                       point a hook (which runs with a fixed, flag-less command line) at a
                       non-default store
      --dry-run        Parse and report; write nothing
      --read-only      Open the store in read-only mode (refuses ingest)
      --no-index       Skip wiring up the Tantivy hook on open. Use for storage-only operations that
                       don't need search, or when the Tantivy directory is intentionally absent
      --quiet          Suppress per-file progress lines
      --scope <PATH>   Override the default `codex/<project>` scope for every ingested item
  -h, --help           Print help
